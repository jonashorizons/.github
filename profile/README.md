# Jonas Horizons

**Building freedom. Expanding horizons.**

An independent project by [Jonas Gantner](https://github.com/jonasgantner), an entrepreneur based in Switzerland, exploring how to design a life with more freedom, opportunities and experiences.

## About this GitHub

A home for scripts, workflows, and open-source experiments in AI automation, macOS productivity, and e-commerce operations. I’m interested in tools that take repetitive work off your plate and give you more time for the things you want to do.

## Featured projects

- [Prompt Picker](https://github.com/jonasgantner/prompt-picker) — a macOS menu bar app for finding and combining reusable AI prompts from Markdown files. [Download the app](https://github.com/jonasgantner/prompt-picker/releases/latest).
- [Things 3 Keyboard Shortcuts](https://github.com/jonasgantner/anki-things3-shortcuts) — a downloadable Anki deck with 102 shortcuts for learning to use Things 3 from the keyboard.
